# Joining Hands Learning Portal

## Files
- index.html
- styles.css
- app.js

## How to use
1. Keep all three files in the same folder.
2. Keep your uploaded `Project 1.png` through `Project 14.png` files in the same folder.
3. Open `index.html` in the browser, or run it with your existing local server.
4. The MS Word learning dashboard includes Home, Insert, Design, Layout, References, Mailings, Review and View.
5. Use Hindi/English buttons, dark mode and image zoom.

No external libraries are required.
